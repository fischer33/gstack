# Designly – ein Canva-Klon

Grafik-Editor im Browser. Eine einzige Datei (`index.html`), kein Build, keine Abhängigkeiten.

## Starten

    open canva-clone/index.html      # oder: python3 -m http.server -d canva-clone

## Funktionen

- Text, Formen (Rechteck, Kreis, Dreieck, Stern, Linie) und Bilder (Upload, Drag & Drop, Strg+V)
- Verschieben, Skalieren, Drehen (Shift = 15°-Raster), Magnet-Hilfslinien zur Mitte
- Doppelklick zum Texteditieren, 8 Schriften, Fett/Kursiv/Ausrichtung
- Füllung, Rahmen, Rundung, Deckkraft, Ebenen-Reihenfolge, Zentrieren
- Vorlagen, Formatvorgaben (Instagram, Story, Poster, Folie, A4, Header)
- Undo/Redo, Autosave (localStorage), Speichern/Öffnen als JSON, PNG-Export in voller Auflösung
- Tasten: Strg+Z/Y, Strg+C/V/D, Entf, Pfeile (Shift = 10px), Esc, Strg+Mausrad = Zoom
